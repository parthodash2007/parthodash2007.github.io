গুণগত রসায়ন

পড়ার উপকরণ দেখতে একটি বিষয় নির্বাচন করো।

০১পরমাণু ও তার মূল কণিকাসমূহ ০২আইসোটোপ, আইসোটোন, আইসোবার ও আইসোইলেকট্রনিক ০৩পারমাণবিক ভর ও আপেক্ষিক পারমাণবিক ভর সংক্রান্ত ০৪রাদারফোর্ড, বোর পরমাণু মডেল ও নিউক্লিয়ার বিক্রিয়া ০৫অরবিট, অরবিটাল এবং কোয়ান্টাম সংখ্যা সংক্রান্ত ০৬ইলেকট্রন বিন্যাসের নিয়ম নীতি সংক্রান্ত ০৭কোয়ান্টাম বলবিদ্যা ব্যবহার করে ইলেকট্রনের বিভিন্ন শক্তির রাশি নির্ণয় সংক্রান্ত সমস্যা ০৮বর্ণালি ও রিডবার্গ সমীকরণ সংক্রান্ত সমস্যা এবং বর্ণালির ব্যবহার ০৯দ্রাব্যতা ও দ্রাব্যতা গুণফল বিভিন্ন নিয়ামকের প্রভাব ১০দ্রাব্যতা গুণফল ও আয়নিক গুণফল সংক্রান্ত সমস্যা ১১আয়ন শনাক্তকরণ ১২গুণগত রসায়নের প্রয়োগ (বিশোধন প্রণালী) ১৩সকল গুরুত্বপূর্ণ টপিক

০১ 🧪 T-07: কোয়ান্টাম বলবিদ্যা ব্যবহার করে ইলেকট্রনের বিভিন্ন গতীয় রাশি নির্ণয় সংক্রান্ত সমস্যা

০২ 💡 Concept

📥 ইলেকট্রনের গতীয় রাশি নির্ণয়

• বোর মডেল অনুযায়ী নির্দিষ্ট কক্ষপথের ইলেকট্রনের বেগ, ব্যাসার্ধ ও শক্তি নির্ণয়:

রাশি   |   সূত্র

কক্ষপথে ইলেকট্রনের বেগ   |   \(V_n = \frac{2.18 \times 10^6 \times Z}{n} \text{ ms}^{-1}\)

কক্ষপথের ব্যাসার্ধ   |   \(r_n = \frac{n^2}{Z} \times 5.29 \times 10^{-11}\text{ m} = \frac{n^2}{Z} \times 0.529\text{ \AA} \quad [1\text{ \AA} = 10^{-10}\text{ m}]\)

কক্ষপথের মোট শক্তি   |   \(E_n = -2.18 \times 10^{-18} \times \frac{Z^2}{n^2} \text{ J/atom} = -13.6 \times \frac{Z^2}{n^2} \text{ eV/atom}\)

কক্ষপথে ইলেকট্রনের কৌণিক ভরবেগ   |   \(L = \text{mvr} = \frac{nh}{2\pi} \qquad \text{[SUST'25-26]}\)

এখানে,

• \(V_n = n\text{-তম কক্ষপথে ইলেকট্রনের বেগ } (\text{ms}^{-1})\)

• \(n = \text{কক্ষপথ সংখ্যা}\)

• \(m = \text{ইলেকট্রনের ভর } = 9.1 \times 10^{-31}\text{ kg}\)

• \(h = \text{প্লাঙ্কের ধ্রুবক } = 6.626 \times 10^{-34}\text{ J}\cdot\text{sec}\)

• \(r_n = n\text{-তম কক্ষপথের ব্যাসার্ধ } (\text{m এককে})\)

• \(E_n = \text{কক্ষপথের শক্তি } (\text{J এককে})\)

• \(Z = \text{পারমাণবিক সংখ্যা}\)

• \(e = \text{ইলেকট্রনের চার্জ } = 1.602 \times 10^{-19}\text{C}\)

📂 Calculation Hacks

• \(E = \frac{hc}{\lambda}\) (\(\lambda \) এর মান \(6.626\) এর গুণিতক আকারে দিয়ে থাকলে \(h\) এর মানের সাথে ভাগ করতে সুবিধা হয়।)

• কোনো তরঙ্গের তরঙ্গদৈর্ঘ্য \(1.324 \times 10^{-6}\text{ m}\) হলে ঐ তরঙ্গের শক্তি নির্ণয় কর:

• \(E = \frac{hc}{\lambda} = \frac{6.626 \times 10^{-34} \times 3 \times 10^8}{1.324 \times 10^{-6}} = \frac{6.626 \times 3}{1.324} \times 10^{-20} = 1.5 \times 10^{-19} \times 10^{-1} = 1.5 \times 10^{-20}\text{ J}\)

শিরোনাম   |   মূল তথ্য   |   সূত্রাবলি

ডি-ব্রগলি তরঙ্গ সমীকরণ   |   ইলেকট্রনের কণা ও তরঙ্গ ধর্ম প্রকাশ   |   \(\lambda = \frac{h}{mv} = \frac{h}{p}\) ; এখানে \(p = \text{ভরবেগ}\)

হাইজেনবার্গের অনিশ্চয়তা নীতি   |   ইলেকট্রনের অবস্থান ও ভরবেগ একইসাথে সঠিকভাবে নির্ণয় সম্ভব নয়।   |   \(\Delta x \times \Delta p \geq \frac{h}{4\pi}\) ;

\(\Delta x = \text{অবস্থান নির্ণয়ে অনিশ্চয়তা}\)

\(\Delta p = \text{ভরবেগ নির্ণয়ে অনিশ্চয়তা}\)

শ্রোডিঞ্জার তরঙ্গ সমীকরণ   |   তরঙ্গরূপী ইলেকট্রনের গতিভাব ব্যাখ্যার জন্য ত্রিমাত্রিক (x, y, z) তরঙ্গ সমীকরণ উপস্থাপন।   |   \(\frac{\partial^2\psi}{\partial x^2} + \frac{\partial^2\psi}{\partial y^2} + \frac{\partial^2\psi}{\partial z^2} + \frac{8\pi^2m}{h^2}(E-V)\psi = 0\)

\(E = \text{ইলেকট্রনের মোট শক্তি}\) ; \(V = \text{স্থিতিশক্তি}\) ; \((x,y,z)\)

প্লাঙ্কের কোয়ান্টাম সূত্র   |   \(h = \text{প্লাঙ্কের ধ্রুবক} = 6.626 \times 10^{-34}\text{ J}\cdot\text{s}\);\(\Delta E = \text{নিঃসারিত বা শোষিত শক্তি}\);\(\nu = \text{কম্পাঙ্ক}\); \(\lambda = \text{তরঙ্গদৈর্ঘ্য}\); \(c = \text{আলোর বেগ}\)[শক্তির শোষণ বা বিকিরণের মান এর কম্পাঙ্কের সমানুপাতিক।]   |   \(\Delta E = h\nu = \frac{hc}{\lambda}\)

• বোরের মডেল অনুযায়ী, \(\text{mvr} = \frac{nh}{2\pi} \Rightarrow 2\pi\text{r} = n\frac{h}{\text{mv}} = n\lambda\)

• \(\Rightarrow 2\pi\text{r} = n\lambda\) [ডি-ব্রগলি অনুযায়ী]

• প্রথম কক্ষপথে \(n = 1\) অর্থাৎ \(2\pi\text{r} = \lambda\) (পূর্ণ তরঙ্গ ১ টি)

• ২য় কক্ষপথে \(n = 2\) অর্থাৎ \(2\pi\text{r} = 2\lambda\) (পূর্ণ তরঙ্গ ২ টি)

• যেহেতু, চিত্রটিতে ঘূর্ণায়মান ইলেকট্রন ৫ টি পূর্ণ তরঙ্গ সম্পন্ন করেছে, সেহেতু, এটি ৫ তম কক্ষপথ।

(ডানপাশে চিত্র: ইলেকট্রন মেঘের তরঙ্গরূপ এবং নিউক্লিয়াস দেখানো হয়েছে, যেখানে ৫টি পূর্ণ তরঙ্গ বা লুপ আছে)
